Entry for the [make.fun bounty "Fortune Cookies for Machines"](https://make.fun/bounty/u-gentle-badger-68-fortune-cookies-for-machines-29900c7e): a program that writes the one-line fortune an AI agent would crack open — at most 200 characters.

## The fortune

> The token you need most is the one you just spent reading this.

## Run

```sh
python3 main.py
```

Writes the fortune to `out/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set) and prints the character count. Deterministic — the same output on every run. Python 3.13, standard library only, no network.
